Identity, bounds,
then a narrow transaction.

The EditorWindow records only permitted commands. Preview computes their result. Restore and replay refuse unrecorded drift, preserve root membership and use native Undo wiring.

Inside the experimental EditorWindow

  1. Capture a clean saved scene root and its stable IDs, controlled fields and dependency identities.
  2. Record and apply a position, scale, rotation, name or active command through the window.
  3. Preview the full plan against current identity guards and displacement/scale invariants.
  4. Restore, then replay from the captured checkpoint. A failure requires rollback verification of the captured fields.

The initial adapter rejects scripts, missing scripts, colliders, physics, animation, prefab instances and unknown components. It does not create/delete/reparent objects or execute reflection expressions.

Run the verified executable

The CLI ZIP includes its .NET runtime. Extract it and run:

./UnityReplay.Cli.exe demo ./demo
./UnityReplay.Cli.exe verify ./demo/manifest.json ./demo/baseline.json ./demo/context.json ./demo ./demo/plan.json

It checks actual asset/meta bytes, then replays the bounded policy model. The separate UPM ZIP contains the experimental Editor integration.

Guarded does not mean universal.

The guarantee covers declared local fields. It does not establish visual, physics, build-output or complete Editor equivalence. Global Editor callbacks can have effects outside the captured fields, and native Undo rollback remains unverified.

Caps limit objects, commands, assets and file sizes. Hashes detect drift relative to the captured manifest; they are not publisher signatures.

A layer above existing scene tools

UnityYAMLMerge, Scene Diff, PrefabLens and SceneXRay already cover substantial semantic comparison and dependency inspection. This project focuses on a small command contract and explicit refusal conditions.
